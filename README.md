Минималистичная клавиатура Goy Keyboard, для использования альтернативного Layout "ЙЦУКЕН".
# Использование
- Двойное нажатие кнопки переключения Layout активирует goy mode.
- Удерживание кнопки переключения Layout активирует панель эмоджи.
- Свайп вправо кнопки переключения Layout активирует панель цифр.
